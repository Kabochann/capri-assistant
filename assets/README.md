# Avatar

Coloque aqui as imagens do seu avatar (PNG com fundo transparente é o ideal).
O programa procura estes nomes:

| Arquivo          | Quando aparece                                        |
|------------------|-------------------------------------------------------|
| `idle.png`       | parada, esperando                                     |
| `listening.png`  | ouvindo você                                          |
| `thinking.png`   | pensando na resposta                                  |
| `speaking.png`   | falando (boca fechada ou posição 1)                   |
| `speaking2.png`  | falando (boca aberta); alterna com `speaking.png`     |

Só o `idle.png` é obrigatório. O que faltar usa o `idle.png`, e se não houver
nenhuma imagem o programa mostra um orbe colorido genérico.

Por padrão o `.gitignore` não envia suas imagens para o GitHub.
